Bagaimana Git-as-a-Database Bekerja?

Website ini sepenuhnya portabel dan bebas biaya server database konvensional. Setiap kali Anda memperbarui atau menambah data melalui Panel Admin CMS, GitHub REST API akan secara otomatis memperbarui file data.json dan mengunggah aset ke folder penyimpanan.

1

Input Melalui Panel Admin

Admin mengisi form dan melampirkan berkas langsung lewat browser dengan verifikasi token aman.

2

Pembaruan Otomatis

Sistem melakukan commit ke repository dan halaman publik langsung memperbarui data secara real-time.
