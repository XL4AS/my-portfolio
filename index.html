Bagaimana Git-as-a-Database Bekerja?

Website ini tidak memerlukan database konvensional seperti MySQL yang berjalan di server terpisah. Setiap kali Anda mengunggah gambar atau deskripsi proyek baru melalui Halaman Admin CMS, sistem secara otomatis melakukan commit & push file Markdown serta aset gambar langsung ke repository GitHub Anda.

1. Upload via Admin

Admin mengisi form dan mengunggah berkas proyek dengan mudah lewat browser.

2. Auto-Rebuild Vercel

GitHub mendeteksi perubahan data dan Vercel langsung memperbarui halaman web.
